# dietmemo

女性のための、からだの記録アプリ「からだログ」。

ダイエッターの趣味で「こんなのあったらいいな！」を形にしたアプリです。内容はあくまで目安なので、ご自身の判断でご使用ください。

## できること

- 体重・歩数・サイズ、食べたもの（1食目〜）、運動・ほぐし、薬・サプリ、メッセージの記録
- 「明日の自分へ」に書いたことが、翌日のホームに届く
- 週・月のカレンダーと、見たいときだけ開くグラフ
- 悩み別・ジャンル別のガイド、自宅用セルフケアグッズ紹介、SNSでよく見る言葉
- 月経の項目は使うかどうかを最初に選べる
- 1日の区切りを自分の起きる時間に合わせられる（夜型・夜勤向け）
- きせかえ（ピンク・水色・白・黒）

## データについて

登録はいりません。記録はその端末のブラウザの中だけに保存され、外に送られることはありません。
